# GGCF full-page Paper designs

Paper file: https://app.paper.design/file/01M4EF9BJ4BBEM40QX2PFG7QCC/p-1-0

Artboards 07–11 contain complete Home, About, Donate, Contact, and 404 layouts at 1440px desktop and 390px mobile. Artboard 12 retains the second original carousel slide at both sizes. Artboard 13 records mobile navigation, donation selection and interaction behavior. These full-page designs supersede the earlier composition studies.

Typography specification: Clash Display Semibold 600 wordmark; Switzer Medium 500 headings and buttons; Switzer Regular 400 body. Official desktop packages and licenses are installed. Both families are now applied in Paper. All thirteen full-page and state artboards were checked: no fallback font families and no horizontal overflow.

All original headings, paragraphs, team quotes, roles, payment details, fields and calls to action are preserved. Existing animated counters are represented by their final values. No new impact claims or donation prices were added. Main-page copy was checked against the repository; alternate carousel and dropdown content appear on the state artboards.

Layout checks: all ten imported Paper pages have the intended widths and no horizontal overflow. Desktop local previews also passed image-loading checks. Final typography was checked after the browser font refresh.

Motion specification: 700ms hero reveal, 650ms section reveal, maximum 34px desktop photographic parallax, maximum 1.5° card tilt, 200ms control feedback. Reduced motion and mobile use static photography. These are design specifications, not new production implementation.

The inline HTML files are editable import sources; build.py extracts the original repository copy. The preview HTML files are local design review artifacts, not replacements for the live website.
